R137 — исправление накопления резервных копий.

Приложение больше не создаёт полную автоматическую копию при каждом перезапуске. Срок следующего резервирования определяется готовыми копиями на диске и сохраняется между запусками. Прежний интервал — раз в 24 часа; ручное резервирование остаётся доступным.

Исправлена очистка временных файлов резервирования и пробного восстановления, включая SQLite-файлы WAL, SHM и journal. Остатки прерванных операций удаляются при следующем запуске и штатном обслуживании. Очистка распознаёт собственные имена приложения, не проходит по вложенным каталогам и поддерживает перенос папки backups через Windows Junction.

Одновременные автоматические запросы больше не создают повторные полные копии. Сохраняется ротация до семи готовых копий; она продолжает удаление других старых копий, если один файл заблокирован. Рабочая база открывается только для чтения и проверяется перед созданием копии: отсутствующий файл больше не превращается в пустую базу.

На Windows прошли 214 нативных тестов, ошибок нет, два прежних теста остаются пропущенными. Проверены все 11 новых сценариев резервирования и четыре существующие сетевые регрессии отправки на печать. Изменения логики ограничены двумя согласованными файлами механизма резервирования; также обновлены служебные данные версии R137.
