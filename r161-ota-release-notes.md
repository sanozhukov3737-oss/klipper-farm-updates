# Klipper Farm 1.15.11

Сборка: `V20.6-R15.11-UPDATE-DELIVERY-PRODUCTION-CANDIDATE-2026-11-15`, sequence 161.

## Что исправлено

**Камера больше не зависит от одного адреса.** Раньше программа спрашивала поток по
единственному адресу и, не получив ответа, сдавалась. На ваших принтерах порт с камерой
оказался разным:

```
Ender-3 V3 KE 02 / K1C : 80 открыт, 8081 открыт, 8000 открыт, 8080 ЗАКРЫТ
Creality K1 Max        : 80 открыт, 8081 открыт, 8000 ЗАКРЫТ,  8080 ЗАКРЫТ
```

Отсюда и было «то показывает, то нет»: всё зависело от того, какой порт сегодня ответит.
Для K1C программа шла на закрытый 8080, для K1 Max — на закрытый 8000.

Теперь адреса перебираются по очереди: 8080, 8081, 80, 4408 с путями `/stream`,
`/?action=stream`, `/webcam/?action=stream`. Ответил — камера включается и перебор
останавливается. Молчит — четыре секунды и следующий адрес. Если не ответил ни один,
пробуется WebRTC, а после него — ещё один проход по адресам.

## Что изменилось для вас

Ничего, кроме камеры. Остальное управление, печать и учёт — без изменений.

## Как обновиться

Нажмите «Установить». Появится окно прогресса, при обрыве скачивание продолжится
с того же места.

## Примечания

- Если камера не появится и теперь, значит поток не запущен на самом принтере —
  адрес придётся взять из его веб-интерфейса.
- Кнопка «Повторить» в области камеры начинает перебор заново с первого адреса.
