# Голосовой помощник — первая версия, на базе R144

Новая функция подготовлена для Klipper Farm. Это исходники предварительной версии, не опубликованное обновление Windows. Канал обновлений остаётся на R144.

## Что добавлено

- Кнопка «Помощник» в боковой панели, компактная панель в цветах приложения.
- Микрофон включается по кнопке на одну фразу, максимум на 20 секунд. Звук не отправляется во внешние сервисы и не записывается на диск.
- Локальное распознавание русского языка Vosk, модель и WASM-движок включены в приложение; облачный Web Speech Recognition не используется.
- «Сколько осталось пластика?», «Остаток пластика», «Сколько пластика на K1 Max?» — ответы из действующего учёта. Общий запас включает свободный пластик и катушки без двойного счёта. Ответы отмечены как данные учёта, а не показания датчика веса.
- «Какие принтеры свободны?» — текущие карточки фермы.
- «Найди корпус», «Напечатай корпус на кей один макс», «Найди корпус и поставь на печать на K1 Max» — поиск по частям имени и папкам в «Моей флешке» с разделением библиотек моделей.
- При нескольких совпадениях помощник предлагает конкретные пары файл/принтер. Можно нажать вариант либо сказать «Выбери первый», «Выбери второй».
- Перед печатью используется общий потоковый анализ всего G-code, проверка совместимости и привязка SHA256 к выбранному файлу.
- Для запуска нужно отдельное «Подтверждаю печать» либо кнопка подтверждения. Подтверждение действительно 90 секунд и используется один раз.
- Занятый/неподключённый принтер, конфликт модели, смена IP/профиля/соединения или недостаточные права блокируют запуск. Готовность дополнительно проверяется свежими ответами принтера перед передачей и перед стартом.
- При неопределённом ответе команда не повторяется. «Проверь запуск» выполняет только чтение состояния существующей печати.
- Озвучивание использует только установленный локальный русский голос Windows. При его отсутствии остаются текстовые ответы и распознавание речи; облачный голос не подставляется.
- «Отмена» сбрасывает неподтверждённое действие. Это не аварийная остановка уже начавшейся печати.

## Проверки и границы

29 автоматических сценариев логики, TypeScript и production-сборка. Проверены прежние сценарии R144, в том числе 15 сценариев аварии/восстановления, 92 проверки имён файлов, потоковая проверка G-code и защита выбранного принтера.

Браузерная проверка запускает настоящий Vosk WASM и обработчик микрофона с синтетическим русским аудио. Внешние запросы блокируются. Нативное хранилище и принтер в этой проверке представлены тестовыми адаптерами: реальная печать на устройствах и установленный WebView2 Windows ещё не проверялись.

Распознавание названий зависит от произношения, шума и словаря модели. Неизвестная команда предлагает уточнение; запуск по приблизительному совпадению без отдельного подтверждения не выполняется. Панель понимает перечисленные команды и не является разговорной языковой моделью.

## Воспроизведение

- `npm ci`, `npm run build`, `npm run check:voice`.
- `node ui-tests/voice-assistant-r145.mjs`: интерфейс и передача/подтверждение через тестовый адаптер.
- `KF_VOICE_AUDIO` — путь к WAV 48 кГц с вопросом об остатке пластика; включает проверку аудиофайла через тестовый микрофон Chromium.
- `KF_VOICE_FIXTURES` — каталог `print.wav` и `confirm.wav`; дополнительно проверяет отдельные голосовые выбор файла/принтера и подтверждение через WAV-backed MediaStream.
- `PLAYWRIGHT_MODULE_PATH`, `CHROMIUM_EXECUTABLE` задают установленный Playwright/Chromium.
- Речевая модель поставляется в `public/voice`. `prepare-voice-model.py` воспроизводит её упаковку из официального ZIP с проверкой исходного SHA256. `prepare-voice-runtime.mjs` воспроизводит адаптацию зафиксированного Vosk-Browser 0.0.8 к CSP без JavaScript unsafe-eval.

Речевая модель и runtime распространяются с уведомлениями и лицензией Apache-2.0 в `public/voice`. Сборка проверяет хеши включённых файлов.

Облегчённый архив исходников для просмотра не содержит воспроизводимый 46-МБ файл `public/voice/ru-small.tar.gz`. В нём сохранены его хеши, лицензия, официальный адрес исходной модели и упаковщик. Для подготовки модели скачайте `https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip` и выполните `python scripts/prepare-voice-model.py ПУТЬ_К_ZIP`. Эта операция нужна при подготовке сборки: установленный помощник должен получать модель вместе с установщиком и работать без скачиваний.
