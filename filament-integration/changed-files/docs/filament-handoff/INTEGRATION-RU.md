# Утверждённый пластик — интеграция поверх R131

Это изменение реальных React/TypeScript-компонентов приложения. Канал обновлений, версия установленного приложения и установщик не изменяются.

Основа: официальный `KF-R131-FULL.zip`, SHA-256 `0ed98e2960845b92c5d4c7888494b7deddbf0141d3127fd6e5832f7ccc2dff0f`. Рендерер `src/lib/spool-viewer.mjs` перенесён побайтно из архива передачи; SHA-256 `6b3649ec27e6d1c54e124d9a4df8610d3e35283de40eebd633ff688b54b9f7f3`. Геометрия широких чёрных спиц, обода, этикетки и намотки сохранена. Контрольный вариант 680 г имеет 1 081 728 вершин.

## Поведение

- `FilamentWarehouse` показывает утверждённую компоновку: общий запас, материалы, выбранная катушка, цвет, поверхность и остаток. По умолчанию открыта карточка; отдельная кнопка включает крупный просмотр с масштабом и поворотом. Ни один ползунок не меняет учёт.
- Итоги выводятся из `production.filamentInventory`: каждая катушка учитывается один раз; считаются только непустые катушки, отдельно установленные и свободные. Имеющийся запас без отдельных катушек включён в массу и подписан отдельно. Итоги по материалам сходятся с общей массой.
- `finish` — необязательное поле `normal` / `silk` / `matte`. Старые записи читаются без переписывания, отображаются с обычной поверхностью. Серийный номер, партия, порядковый номер и корректный EAN-8 передаются только из существующих метаданных. Ничего не генерируется вместо отсутствующих данных.
- Остаток корректируется штатной формой. Отдельная команда внешнего вида меняет только цвет/поверхность и не возвращает старый остаток после параллельного списания.
- Замена использует существующее сериализованное хранилище и единую SQLite-команду `filament_inventory_commit`. Старая катушка возвращается на склад, новая устанавливается, выбор в карточке следует за новой катушкой. Масса и накопленный расход не меняются. Отмена не пишет данные. Пустые/занятые катушки и устаревшее назначение отвергаются; сбой записи сохраняет предыдущее состояние.
- Карточки главной страницы, вкладки «Принтеры», склада, форм и диалога замены используют общие миниатюры с реальными цветом, поверхностью, массой, ёмкостью и диаметром.
- Один подробный просмотр и максимум один общий последовательный генератор миниатюр. Кэш ограничен 64 PNG, ключ содержит описание, ракурс и версию модели. Работа для ушедших за экран карточек отменяется; во время перетаскивания новая генерация не начинается. Генератор освобождает GPU после простоя, просмотр — при размонтировании. Без WebGL и при потере контекста остаются изображение, текст и доступные действия; просмотр можно пересоздать.
- Панель времени освобождения принтеров и видимые кнопки «Открыть» / «Повторить», удалённые в R131, не возвращаются. Вся карточка принтера по-прежнему открывается нажатием и с клавиатуры.

## Проверки

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
node scripts/check-approved-filament.mjs
node scripts/check-filament-inventory.mjs
node scripts/check-r127-filament.mjs
node scripts/check-filament-telemetry.mjs
node scripts/check-printer-config-persistence.mjs
```

Браузерные сценарии (нужны Playwright и Chromium; при необходимости задать `PLAYWRIGHT_MODULE_PATH`, `CHROMIUM_EXECUTABLE`, `KF_UI_SCREENSHOTS`):

```sh
node ui-tests/approved-filament.mjs
node ui-tests/filament-inventory.mjs
node ui-tests/filament-warehouse.mjs
node ui-tests/filament-replace-r129.mjs
node ui-tests/printers-r130.mjs
node ui-tests/fleet-live-r128.mjs
```

Проверки используют настоящие компоненты, reducer и store с искусственными данными только в `ui-tests`. Нативная граница SQLite/desktop в браузере заменена воспроизводимым адаптером. Проверяются сохранение после перезагрузки, откат ошибки записи, конфликт замены, цвет/поверхность/остаток, пустая/полная катушки, ёмкость 2 кг, обе темы, клавиатура, resize, потеря контекста и отсутствие WebGL. Максимум контекстов и ограничение кэша проверяются в браузере.

В этой работе не проверяются реальная база пользователя, расход на физических принтерах, запуск Windows/WebView2 на GPU пользователя и установщик. Для публикации требуется отдельное задание, новый номер сборки и штатная Windows-проверка.
