R135 — рамки склада пластика, автоматический учёт и подтверждение запуска печати.

В разделе «Пластик» сохранены исходные ширина, фон и расположение элементов. Одна скруглённая рамка объединяет большую катушку и все сведения о ней, вторая — «Запас и резерв» с карточками материалов.

Убраны блок «Расход по принтерам», ручное списание и подтверждение ожидающего расхода. Приложение автоматически повторяет сверку истории после восстановления связи и учитывает полученный фактический расход. Неизвестный расход не подменяется весом файла; повторное получение данных не создаёт повторного списания.

Для Flashforge Adventurer 5M исправлена обработка вложенных ответов состояния. После задержки ответа приложение автоматически наблюдает за запуском. Неопределённый результат не вызывает повторную загрузку файла или вторую команду запуска. В сетевой части Windows восстановление связи после принятой команды выполняет только чтение состояния; первый REST-запуск допускается только при доказанном отказе WebSocket до приёма команды.

Скруглены карточки файлов принтера и локальной библиотеки; сведения и действия помещаются внутри карточек. Сохранение исходных имён файлов из R134 осталось без изменений.

Проверены сборка Windows, установка поверх R134, сохранность принтеров и запасов пластика, точное совпадение установленных файлов с пакетом и повторный запуск приложения. Нативные тесты: 203 passed, 0 failed, 2 ранее существовавших пропуска. Проверки запуска и учёта использовали настоящие обработчики приложения и локальные эмуляторы. Физические принтеры пользователя не подключались.
