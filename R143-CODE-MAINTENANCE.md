# Klipper Farm R143

Стабильный выпуск опубликован: https://github.com/sanozhukov3737-oss/klipper-farm-updates/releases/tag/r143-ota

## Изменения

- MJPEG-изображения освобождают источник при закрытии камеры. WebRTC освобождает принадлежащие просмотрщику дорожки и соединение.
- Геометрия утверждённой катушки формируется во временных Float32-буферах. Современный WebView2 освобождает их внешнюю память сразу после копирования в WebGL и при росте; для старых движков сохранён совместимый вариант.
- Удалены 690 перекрытых CSS-деклараций, 19 329 байт, с сохранением оформления.
- 16 нативных команд библиотеки выделены в модуль с сохранением тел, разрешений и интерфейсов. Выделен мост акторов принтеров.
- Добавлены сравнения геометрии, оформления и ресурсов с точным опубликованным R142.
