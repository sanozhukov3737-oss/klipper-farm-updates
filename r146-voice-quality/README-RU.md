# Исправление качества голоса и распознавания

Подготовлено локально. Новый Windows-установщик не собран и не опубликован.

Изменения:

- Обычные команды распознаёт локальный Whisper small q5_1; Vosk оставлен для отдельного короткого подтверждения печати.
- Захват микрофона ждёт 1,8 секунды тишины, сохраняет фразу целиком, ограничен 20 секундами. Звук передаётся локальному процессу через память и stdin, без записи микрофона на диск и без сетевых запросов.
- Системный голос заменён в панели на Piper: Денис и Дмитрий, с выбором и кнопкой прослушивания.
- Понимается порядок «Принтер К1 Макс, поставь на печать корпус» и вариант «К1 мах». Конфликтующие цели, отрицание и повторное подтверждение не запускают печать.
- Неуверенное распознавание Whisper само по себе не может подтвердить запуск. Проверки выбранного файла, SHA256, модели и готовности принтера сохранены.
- Речевые инструменты и модели готовятся при сборке по зафиксированным SHA256 и включаются в ресурсы установщика.

Проверено:

- 30 сценариев команд и управления; 8 сценариев записи, отмены и озвучивания.
- 4 Rust-теста работы процессов, тайм-аута, ограничения вывода и проверки WAV.
- Отдельная проверка типов полного нового Rust-модуля со служебными заглушками API приложения.
- TypeScript, production-сборка интерфейса, проверки авторизации и выбранного принтера.
- 6 браузерных сценариев с тестовым адаптером: выбор голоса, текстовая команда с принтером в начале, отдельное подтверждение, отсутствие повторного запуска, закрытие панели, отсутствие внешних запросов и исключений.
- Настоящие Piper и Whisper на CPU: синтетическая фраза «Принтер кей один макс, поставь на печать корпус» распознана как «Принтер K1 Max поставь на печать, корпус».

Не проверено: аппаратный микрофон пользователя, реальные принтеры, новая сборка и установленный WebView2 Windows. Полная Linux-проверка Tauri остановилась до проверки приложения из-за отсутствия pkg-config/GLib. Проверка модуля со заглушками не заменяет сборку Tauri.

Применение к исходникам приложения из проверенной предварительной сборки R145:

```powershell
python r146-voice-quality/apply.py ПУТЬ_К_ИСХОДНИКАМ_ПРИЛОЖЕНИЯ
cd ПУТЬ_К_ИСХОДНИКАМ_ПРИЛОЖЕНИЯ
python scripts/prepare-neural-speech.py
npm ci
npm run check:voice
npm run check:neural-speech
npm run build
node scripts/build-and-install-windows.mjs --build-only
```

Нужны оставшиеся проверки упаковки и установщика Windows. Служебный workflow выгрузки исходников не добавлен: автоматическая проверка его отклонила. Создание удалённой ветки отдельно вернуло 403 Resource not accessible by integration. Локальная ветка содержит только подготовленный пакет исправления и результаты проверок.
