# Русский офлайн-голос Ксения для Klipper Farm

Пользователь выбрал образец № 1: Silero `v5_6_ru`, speaker `kseniya`.
Ксения установлена голосом по умолчанию в интерфейсе и в нативной границе озвучивания.
Синтез возвращает PCM16 mono 48 кГц через память; высота и темп не изменяются.

Для Windows подготовлен самостоятельный пакет Python 3.12.10 и PyTorch 2.5.1 CPU.
Системный Python и загрузка моделей при запуске не нужны. Все архивы, wheels и модель
закреплены URL, размером и SHA-256; устаревшие файлы Piper исключаются при подготовке.
Рабочий процесс принимает русский UTF-8 через stdin, изолирует Python от пользовательских
настроек, запрещает сетевые соединения и завершается после ответа.

Числа, температура, масса пластика, проценты и время переводятся в русские слова перед
синтезом. В частности, `23 минуты`, `250°C`, `1.500 кг`, `20:34` проговариваются полностью;
`K1 Max` читается как «кей один макс». Нативные пределы текста, размера PCM, времени работы
и существующая отмена запоздалого воспроизведения сохранены.

Распознавание остаётся на локальном Whisper.cpp small-q5_1. Подтверждение печати по-прежнему
отделено от распознавания: выбор файла, проверка готовности и отдельное подтверждение.
Реальные принтеры и аппаратный микрофон в локальных проверках не использовались.

Подтверждено локально: TypeScript; 31 проверка команд; 8 проверок речевого цикла;
7 браузерных проверок интерфейса с голосом `kseniya`; полный production build;
проверка ресурсов, контракта безопасности, frontend/native контракта и переносимости релиза. Реальный адаптер синтезировал и успешно
прошёл проверку текста с названием принтера и числительными в изолированном Linux Python.
Это не заменяет Windows-тест.

CI подготовлен для проверки комплектного Windows Python, полного Rust/Clippy прогона,
установщика и озвучивания в настоящем установленном WebView2. Каталог установки теста
содержит кириллицу. Установщик этой ревизии ещё не собран и установленный Windows-клиент
с Ксенией ещё не проверен. Результаты записаны в verification.json и отдельных proof-файлах.
