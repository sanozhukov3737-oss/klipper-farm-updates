# R139 — вентилятор, файлы и автоматическое восстановление адресов

Согласованные исправления реализованы поверх точного опубликованного R138. Локальные проверки завершены; Windows-сборка и публикация ещё предстоят. Текущий стабильный канал — R138.

- Вентилятор управляется мышью и клавиатурой. Одна операция проверяет фактический управляемый выход, отправляет команду и подтверждает полученную скорость. Изменение IP, конфликт устройства и отсутствие связи отменяют управление. Для штатных K1C/K1 Max поддержан подтверждённый конфигурацией `output_pin fan0`; проценты означают фактический PWM, вспомогательный `fan2` не затрагивается.
- Вкладки файлов используют более светлую графитовую палитру с заметными границами и читаемыми недоступными кнопками. Размеры, расположение и скругления сохранены, акценты остаются синими.
- Три карточки с одним IP не получают три независимых статуса «онлайн». Реальные сигналы устройства проверяются до публикации его статуса; противоречащее оборудование временно блокируется. Существующий поиск сети автоматически сохраняет все однозначно подтверждённые адреса одним изменением, включая переставленные IP. Имена, профили, ID и привязки пластика сохраняются.

Автозамена требует подтверждённой физической идентичности: модель и имя сами по себе не выбирают владельца IP. При недостаточных данных неоднозначные карточки показывают проверку, а поиск продолжается. Уникальная ранее настроенная карточка может запомнить фактический аппаратный идентификатор для следующей смены IP.

## Воспроизведение

База: `KF-R138-FULL.zip`, 582302630 байт, SHA-256 `6ca02e8bfd959c42044d6335e9df521d4a9a31d02452f47907c000a1176ca2aa`.

`r139-feature-patch.json` содержит 24 рассмотренных изменения, включая 13 новых файлов. `apply-r139-release.py` проверяет все 1793 исходных файла, применяет изменения и пять служебных параметров версии, затем сверяет все 1806 итоговых файлов. Остальные исходники сохраняются побайтно.

```sh
python apply-r139-release.py KF-R138-FULL.zip Klipper-Farm-R139
```

Первый Windows run `40187958320` остановился на старой текстовой проверке сохранения настроек. Проверка уточнена для отдельной ветки смены IP; дополнительный сценарий настоящего FarmApp подтверждает сохранение подключения при изменении имени. Изолированная проверка телеметрии также загружает фактический новый helper вентилятора. Изменения рабочего кода после первого freeze не вносились.

Второй Windows run `40188843313` прошёл все старые регрессии и 53 новые runtime-проверки, затем остановился на импорте Playwright из Windows-пути. Workflow использует абсолютный file URI; сравнение с R138 CSS нормализует разделители Vite-пути. Изменён только тестовый запуск и проверка, рабочий код сохранён.
