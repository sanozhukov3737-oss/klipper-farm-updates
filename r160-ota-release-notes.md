# Klipper Farm 1.15.10

Сборка: `V20.6-R15.10-UPDATE-DELIVERY-PRODUCTION-CANDIDATE-2026-11-14`, sequence 160.

## Что исправлено

**Ассистент правильно ставит ударения.** Ошибка была не в голосе, а в таблице ударений:
она писалась руками, группами по основе слова, и ошибалась на всех формах, где ударение
уходит с основы.

Слышно было так:

```
было:  «Печать завЕршится», «Печать завЕршена», «Подсветка вклЮчена», минуты без ударения
стало: «Печать завершИтся», «Печать завершенА», «Подсветка включенА», «23 минУты»
```

Заодно исправлено ещё десять записей, которые никто не замечал, потому что они звучали
правдоподобно: `библиотЕка` вместо `библиОтека`, `детАль`, `модЕль`, `настрОйки`,
`грАдусов`, `освободИлся`, `вЫберите`.

**Таблица больше не пишется руками.** Её строит программа по словарю русского ударения
(3,19 млн словоформ) из тех слов, которые приложение действительно произносит. Это значит,
что новая фраза получает правильное ударение сама, а не ждёт, пока кто-то заметит ошибку.

## Что изменилось для вас

Ничего в интерфейсе. Меняется только произношение: ассистент говорит
`зАпуск`, `завершИтся`, `завершенА`, `вЫключена`, `нОмер`, `назовИте`, `сейчАс`,
`библиотЕка`, `детАль`, `модЕль`, `настрОйки`, `грАдусов`.

Слова, где ударение зависит от смысла (`зАмок` и `замОк`), по-прежнему определяются по
контексту, а не по таблице.

## Как обновиться

Нажмите «Установить». Появится окно прогресса, при обрыве скачивание продолжится
с того же места.

## Примечания

- Если какое-то слово всё ещё звучит неверно — назовите фразу, его добавят в словарь.
- Полный список слов таблица получает из строк интерфейса, поэтому новые подписи
  подхватываются автоматически.
